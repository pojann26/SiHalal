# Halal Pre-Audit Assistant — UI Prototype

React + Vite responsive UI starter untuk proyek Sistem Informasi kelompok.

## Menjalankan

```bash
npm install
npm run dev
```

Lalu buka URL Vite yang ditampilkan di terminal.

## Yang sudah tersedia

- Dashboard / progress SJPH
- Self-Assessment workflow
- Matriks Bahan SJPH
- AI Validation result
- Recommendation / review states melalui validasi
- Dokumen SJPH generator & preview
- Asisten Halal chatbot
- Riwayat aktivitas
- Responsive desktop/mobile layout

UI dibuat sebagai prototype/front-end headstart. Integrasi OCR, NLP, database, PDF generator, dan SIHALAL belum diimplementasikan; tombol menggunakan interaksi prototype/toast.
